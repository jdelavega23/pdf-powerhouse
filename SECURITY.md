## 🔒 Reporting a Vulnerability

Security and privacy are the primary foundations of **PDF Powerhouse**. We take all security vulnerabilities seriously.

If you discover a security vulnerability in this project:

1. **Do NOT open a public issue.**
2. Send an email to **`jdelavega23@hotmail.com`** or use GitHub's private vulnerability reporting feature in the Security tab.
3. Include details of the vulnerability, steps to reproduce, and potential impact.

We will acknowledge receipt within 48 hours and work with you on a timely resolution before any public disclosure.
